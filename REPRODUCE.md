# Reproduction and access

The [published metrics](metrics/) can be read directly from a public checkout. To regenerate them, create a Python 3.12 environment and follow the commands in [README.md](README.md) with `requirements-lock.txt`. `environment.yml` provides a conda option. The public source tree includes the aggregate tables. Provider responses, raw geometry and model checkpoints are local artifacts.

1. `acquire.py` selects boundaries and native cells from geometry, measures areas in EPSG:3035 after geographic-segment densification, and retrieves explicit-model ERA5 daily data for 1991–2022. It archives exact JSON and request metadata, checking dates, units, coordinates and finite values. The script spaces requests by 20 seconds. HTTP 429 stops acquisition and preserves the cache so you can resume after the provider's limit resets.
2. `audit_sources.py` verifies NASA collection metadata only. Rerun it after `acquire.py`, which rebuilds the core data manifest. It does not authenticate or retrieve MODIS imagery.
3. `prepare.py` builds `climate_cube.nc` with xarray/Dask and derives fixed-reference thresholds, causal labels, raw-dependency embargoes and samples. It retains leap days and propagates the first 89 unsupported rainfall-history days instead of filling them.
4. `train.py` fits training-only scalers and three predeclared TCN seeds. It selects checkpoints using 2015–2016 validation AP. It fits Platt calibration and F1 thresholds on 2017–2018 development cells, then performs 30 MC-dropout passes on the untouched 2019–2020 conformal set and 2021–2022 test. Logistic/persistence/climatology baselines use the same allowed information. Seeds and hardware are recorded. A missing class in any required partition stops fitting.
5. `evaluate.py` constructs finite-sample-corrected LAC sets directly, without claiming MAPIE execution. It evaluates pooled, weekly-thinned, class-conditional and higher-confidence scenarios, discrimination and episode overlap, spatial-block bootstrap intervals and fully defined uncertainty diagnostics. Nearest-training-window distance uses a training-only standardised summary reference. No conformal-calibration samples are used to fit the forecast model or Platt mapping.
6. `deliver.py` exports/validates native-resolution COGs, case-study extents, figures, QGIS XML/style files and reports. The run manifest records timestamps, input/code/model hashes, software versions, seeds and output validation. Native QGIS loading must be verified separately; XML parsing and file checks do not prove rendering.
7. Run `pytest`. Synthetic arrays are confined to labelled unit tests. Tests cover causal convolution, event rules, calendar handling, raw-history separation, source units, seed repeatability, conformal quantiles/sets, metric denominators and actual COG geometry.

## Lawful expansion

Direct ERA5-Land: create/sign into a free [CDS account](https://cds.climate.copernicus.eu/how-to-api), accept the chosen dataset terms there, and configure the personal token in a user-level `.cdsapirc` outside the repository. Use requests generated from the current dataset form, starting with a small month/area. Never paste tokens into chat or commit them. Raw ERA5-Land temperature is Kelvin; accumulated precipitation has different conventions from these already-daily API depths. A separate validated adapter is needed before replacing sources.

MODIS: use [NASA Earthdata](https://urs.earthdata.nasa.gov/) and the official collection/granule services. Verify the current access mechanism, authorisation and licence for the chosen granules. Preserve QC bits, fill/scaling values, observation time and composite interval. A 16-day NDVI composite must not be treated as available at its start if later acquisitions contributed. Cloud gaps cannot be filled using future outcomes. No credential-dependent MODIS acquisition adapter is claimed as tested.

The 281,000-plus km² design domain would require a substantially larger lawful download and further spatial validation. The current pilot does not fill unacquired regions with predictions. A full-domain run, a 30-year reference, soil-moisture/SPEI definitions and independent numerical EDO/station comparisons remain unexecuted extensions.
